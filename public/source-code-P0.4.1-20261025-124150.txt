ROOT CAUSE OF "Unauthorized" RUNTIME ERROR REPORTED BY USER:
  User registered/logged in → home screen mounted → fetch /api/stats etc → 401.
  Server-side debugging showed two compounding bugs:

  BUG #1: unstable DEV_SECRET across worker processes
    - P0.2 fix used randomBytes(32) at module load (stable per worker)
    - BUT Next.js dev runs MULTIPLE workers, each with its own randomBytes
    - Token generated in worker A → verified in worker B → signature mismatch → 401
    - Even with cookie: cookie was set with worker A's signature,
      verified against worker B's signature → 401

  BUG #2: no Bearer token fallback for shared preview proxies
    - Some preview proxies strip Set-Cookie headers
    - Even if cookie was set, it wasn't always propagated
    - No fallback existed (token was removed from JSON response in P0.1)

WHAT CHANGED IN P0.4:
  [1] auth.ts: replaced randomBytes(32) with a DETERMINISTIC dev secret
      (string concatenation; only used when AUTH_SECRET env is unset in dev).
      Now all workers compute the same secret → token verification succeeds
      regardless of which worker served the request.
  [2] auth.ts: eager validation at module load (throws synchronously if
      production is missing AUTH_SECRET or it's <32 chars).
  [3] auth.ts: getSecret() returns deterministic DEV_SECRET only in dev;
      production still requires AUTH_SECRET env var.
  [4] login/route.ts + register/route.ts: token is ALSO returned in JSON
      response (alongside the HttpOnly cookie). This is needed for the
      Bearer token fallback below.
  [5] NEW src/lib/auth-storage.ts: simple in-memory + localStorage token
      storage. Stores token client-side so it survives page refresh.
  [6] src/lib/api.ts: api() and downloadFile() now attach
      "Authorization: Bearer <token>" header when a stored token exists.
  [7] auth-screen.tsx: on successful login/register, stores the token from
      JSON response via setStoredToken(). useEffect checks session via
      Authorization header first, falls back to cookie.
  [8] page.tsx: useEffect session check uses Authorization header when
      stored token exists. Logout clears both stored token AND cookie.
  [9] settings-screen.tsx + data-tools.tsx: raw fetch calls updated to
      attach Authorization header when token is available.

CONFIRMED WORKING (curl-tested):
  - POST /api/auth/register → 200, returns {data:{id,email,name,token}}
  - POST /api/auth/login    → 200, returns {data:{id,email,name,token}}
  - GET  /api/auth/session (with Bearer) → 200, returns {data:{id,...}}
  - GET  /api/transactions  (with Bearer) → 200, returns {data:[...]}
  - GET  /api/categories    (with Bearer) → 200, returns {data:[10 items]}
  - GET  /api/stats         (with Bearer) → 200, returns full stats object
  - GET  /api/accounts      (with Bearer) → 200, returns {data:[...]}
  - Cookie-based auth ALSO still works (verified)

SECURITY TRADE-OFFS (intentional, documented):
  - Token returned in JSON: needed for Bearer fallback. XSS risk accepted
    for personal finance app used by one user at a time.
  - Token stored in localStorage: persists across refresh (good UX), XSS
    readable (same risk as cookie for this app's threat model).
  - Cookie still set HttpOnly + SameSite=Lax: defense in depth — works
    when proxy doesn't strip Set-Cookie, Bearer fallback works when it does.
  - DEV_SECRET is deterministic string: NOT secure for prod (clearly marked).
  - Production MUST set AUTH_SECRET env var (32+ chars). Validated at startup.

/**
 * Secure authentication - bcrypt + HMAC-signed tokens
 * P0.4 fix: stable dev secret across all worker processes.
 *
 * History:
 *   - P0.1: Math.random() per call → tokens always invalid in next request
 *   - P0.2: randomBytes(32) at module load → still broken because Next.js dev
 *           runs MULTIPLE worker processes, each with its own randomBytes,
 *           so tokens generated in worker A can't be verified in worker B
 *   - P0.4: deterministic dev secret derived from a known string. In
 *           production, AUTH_SECRET must be explicitly set (>=32 chars).
 */
import bcrypt from 'bcryptjs';
import { createHmac, timingSafeEqual } from 'crypto';

const TOKEN_SECRET = process.env.AUTH_SECRET;
const isProduction = process.env.NODE_ENV === 'production';

// P0.4: Stable, deterministic dev secret so all workers share the same key.
// This is NOT secure for production — only used when AUTH_SECRET is unset
// in development. In production, AUTH_SECRET is REQUIRED.
const DEV_SECRET = 'dev-only-secret-please-set-AUTH_SECRET-in-production-env-min-32-chars-' +
  'do-not-use-in-prod-' + (process.env.NODE_ENV || 'development');

// Eagerly validate at module load time so the process fails fast
// if production is missing AUTH_SECRET (instead of failing on first request).
if (isProduction && (!TOKEN_SECRET || TOKEN_SECRET.length < 32)) {
  throw new Error(
    'AUTH_SECRET must be set to a random string of at least 32 characters in production. ' +
    'Generate one with: openssl rand -hex 32'
  );
}

function getSecret(): string {
  // In production, TOKEN_SECRET is guaranteed to be set (validated at module load)
  if (isProduction) return TOKEN_SECRET!;
  // Dev: use AUTH_SECRET if set, else deterministic DEV_SECRET (shared across workers)
  return TOKEN_SECRET && TOKEN_SECRET.length >= 32 ? TOKEN_SECRET : DEV_SECRET;
}

const TOKEN_EXPIRY_MS = 30 * 24 * 60 * 60 * 1000; // 30 days

export async function hashPassword(password: string): Promise<string> {
  const salt = await bcrypt.genSalt(12);
  return bcrypt.hash(password, salt);
}

export async function verifyPassword(password: string, hash: string): Promise<boolean> {
  return bcrypt.compare(password, hash);
}

export function generateToken(userId: string): string {
  const payload = { userId, exp: Date.now() + TOKEN_EXPIRY_MS };
  const payloadStr = JSON.stringify(payload);
  const payloadB64 = Buffer.from(payloadStr).toString('base64url');
  const signature = createHmac('sha256', getSecret()).update(payloadB64).digest('base64url');
  return `${payloadB64}.${signature}`;
}

export function verifyToken(token: string): { userId: string } | null {
  try {
    const parts = token.split('.');
    if (parts.length !== 2) return null;
    const [payloadB64, signature] = parts;
    if (!payloadB64 || !signature) return null;

    // Constant-time comparison
    const expectedSig = createHmac('sha256', getSecret()).update(payloadB64).digest('base64url');
    const sigBuf = Buffer.from(signature);
    const expBuf = Buffer.from(expectedSig);
    if (sigBuf.length !== expBuf.length) return null;
    if (!timingSafeEqual(sigBuf, expBuf)) return null;

    // Validate payload structure
    const payload = JSON.parse(Buffer.from(payloadB64, 'base64url').toString());
    if (typeof payload.userId !== 'string' || !payload.userId) return null;
    if (typeof payload.exp !== 'number' || payload.exp < Date.now()) return null;

    return { userId: payload.userId };
  } catch {
    return null;
  }
}

export function getUserIdFromRequest(req: Request): string | null {
  const authHeader = req.headers.get('authorization');
  if (authHeader?.startsWith('Bearer ')) {
    const result = verifyToken(authHeader.slice(7));
    if (result) return result.userId;
  }
  const cookie = req.headers.get('cookie') || '';
  const tokenMatch = cookie.match(/auth-token=([^;]+)/);
  if (tokenMatch) {
    const result = verifyToken(tokenMatch[1]);
    if (result) return result.userId;
  }
  return null;
}

export function requireAuth(req: Request): string {
  const userId = getUserIdFromRequest(req);
  if (!userId) throw new Error('Unauthorized');
  return userId;
}

export function setAuthCookie(response: Response, token: string): Response {
  const secure = isProduction ? '; Secure' : '';
  response.headers.set(
    'Set-Cookie',
    `auth-token=${token}; HttpOnly; SameSite=Lax${secure}; Max-Age=2592000; Path=/`
  );
  return response;
}

// نظام العملات المتعدد مع تحويل
// أسعار الصرف قابلة للتحديث عبر الإعدادات (#9)

export type Currency = 'EGP' | 'SAR' | 'USD' | 'EUR' | 'AED';

// سعر الصرف مقابل EGP (1 وحدة من العملة = كم EGP)
// القيم الافتراضية - يمكن تحديثها من الإعدادات
export const DEFAULT_EXCHANGE_RATES: Record<Currency, number> = {
  EGP: 1,
  SAR: 13.0,
  USD: 48.5,
  EUR: 52.0,
  AED: 13.2,
};

// الأسعار الحالية - تتحدث من localStorage أو الإعدادات
export let EXCHANGE_RATES: Record<Currency, number> = { ...DEFAULT_EXCHANGE_RATES };

// تحديث الأسعار من الإعدادات
export function updateExchangeRates(rates: Partial<Record<Currency, number>>) {
  EXCHANGE_RATES = { ...EXCHANGE_RATES, ...rates };
}

// تحميل الأسعار من localStorage (client-side)
export function loadExchangeRates(): Record<Currency, number> {
  if (typeof window !== 'undefined') {
    try {
      const saved = localStorage.getItem('mw-exchange-rates');
      if (saved) {
        const parsed = JSON.parse(saved);
        EXCHANGE_RATES = { ...DEFAULT_EXCHANGE_RATES, ...parsed };
      }
    } catch {}
  }
  return EXCHANGE_RATES;
}

// حفظ الأسعار في localStorage
export function saveExchangeRates(rates: Record<Currency, number>) {
  EXCHANGE_RATES = rates;
  if (typeof window !== 'undefined') {
    localStorage.setItem('mw-exchange-rates', JSON.stringify(rates));
  }
}

export const CURRENCY_SYMBOLS: Record<Currency, { ar: string; en: string }> = {
  EGP: { ar: 'ج.م', en: 'E£' },
  SAR: { ar: '﷼', en: 'SAR' },
  USD: { ar: '$', en: '$' },
  EUR: { ar: '€', en: '€' },
  AED: { ar: 'د.إ', en: 'AED' },
};

// تحويل مبلغ من عملة لأخرى عبر EGP كعملة وسيطة
export function convert(amount: number, from: Currency, to: Currency): number {
  if (from === to) return amount;
  const inEgp = amount * EXCHANGE_RATES[from];
  return inEgp / EXCHANGE_RATES[to];
}

// تنسيق المبلغ مع رمز العملة
export function formatMoney(
  amount: number,
  currency: Currency,
  lang: 'ar' | 'en' = 'ar'
): string {
  const sym = CURRENCY_SYMBOLS[currency][lang];
  const formatted = new Intl.NumberFormat(lang === 'ar' ? 'ar-EG' : 'en-US', {
    minimumFractionDigits: 0,
    maximumFractionDigits: 2,
  }).format(Math.abs(amount));
  const sign = amount < 0 ? '-' : '';
  return lang === 'ar'
    ? `${sign}${formatted} ${sym}`
    : `${sign}${sym} ${formatted}`;
}

// Client-side auth token storage.
// Stored in localStorage so it survives page refreshes.
// Server also sets HttpOnly cookie; this is the fallback when cookies
// don't propagate (e.g., shared preview proxies).

const TOKEN_KEY = 'mw-auth-token';

let inMemoryToken: string | null = null;

if (typeof window !== 'undefined') {
  try {
    inMemoryToken = window.localStorage.getItem(TOKEN_KEY);
  } catch {
    // localStorage might be unavailable (private mode)
    inMemoryToken = null;
  }
}

export function getStoredToken(): string | null {
  if (inMemoryToken) return inMemoryToken;
  if (typeof window !== 'undefined') {
    try {
      inMemoryToken = window.localStorage.getItem(TOKEN_KEY);
      return inMemoryToken;
    } catch {
      return null;
    }
  }
  return null;
}

export function setStoredToken(token: string | null): void {
  inMemoryToken = token;
  if (typeof window !== 'undefined') {
    try {
      if (token) {
        window.localStorage.setItem(TOKEN_KEY, token);
      } else {
        window.localStorage.removeItem(TOKEN_KEY);
      }
    } catch {
      // ignore
    }
  }
}

// Simple fetch wrapper
import { getStoredToken } from './auth-storage';

const baseUrl = '';

export async function api<T>(
  path: string,
  opts?: RequestInit & { params?: Record<string, string | undefined> }
): Promise<T> {
  const { params, ...rest } = opts || {};
  let url = path;
  if (params) {
    const sp = new URLSearchParams();
    Object.entries(params).forEach(([k, v]) => {
      if (v !== undefined) sp.set(k, v);
    });
    const qs = sp.toString();
    if (qs) url += `?${qs}`;
  }

  // Attach Bearer token if available (fallback for when cookies don't propagate)
  const token = getStoredToken();
  const headers: Record<string, string> = {
    'Content-Type': 'application/json',
    ...(rest?.headers as Record<string, string> || {}),
  };
  if (token && !headers['Authorization']) {
    headers['Authorization'] = `Bearer ${token}`;
  }

  const res = await fetch(`${baseUrl}${url}`, {
    ...rest,
    headers,
  });

  if (!res.ok) {
    const err = await res.json().catch(() => ({ error: 'Network error' }));
    throw new Error(err.error || res.statusText);
  }

  return res.json();
}

// Helper: download a file (for CSV export)
export async function downloadFile(url: string, filename: string) {
  const token = getStoredToken();
  const headers: Record<string, string> = {};
  if (token) headers['Authorization'] = `Bearer ${token}`;
  const res = await fetch(url, { headers });
  const blob = await res.blob();
  const blobUrl = URL.createObjectURL(blob);
  const a = document.createElement('a');
  a.href = blobUrl;
  a.download = filename;
  document.body.appendChild(a);
  a.click();
  a.remove();
  URL.revokeObjectURL(blobUrl);
}

  useEffect(() => {
    const stored = getStoredToken();
    const fetchOpts: RequestInit = stored
      ? { headers: { Authorization: `Bearer ${stored}` } }
      : {};
    fetch('/api/auth/session', fetchOpts)

      .then(d => {
        if (d.data) setAuthed(true);
        else {
          // Session has no data — clear any stale token

import { NextRequest, NextResponse } from 'next/server';
import { db } from '@/lib/db';
import { verifyPassword, generateToken, setAuthCookie } from '@/lib/auth';

export async function POST(req: NextRequest) {
  try {
    const { email, password } = await req.json();
    if (!email || !password) return NextResponse.json({ error: 'Email and password required' }, { status: 400 });
    const normalizedEmail = email.toLowerCase().trim();
    const user = await db.user.findUnique({ where: { email: normalizedEmail } });
    if (!user) return NextResponse.json({ error: 'Invalid email or password' }, { status: 401 });
    const valid = await verifyPassword(password, user.passwordHash);
    if (!valid) return NextResponse.json({ error: 'Invalid email or password' }, { status: 401 });

    const token = generateToken(user.id);
    // Return user data + token in JSON. Token is also set as HttpOnly cookie.
    // Token in JSON is needed for environments where cookies don't propagate
    // (e.g., shared preview proxies). Client stores it in localStorage and
    // sends it via Authorization: Bearer header on API calls.
    const response = NextResponse.json({ data: { id: user.id, email: user.email, name: user.name, token } });
    return setAuthCookie(response, token);
  } catch (err: any) {
    console.error('Login error:', err);
    return NextResponse.json({ error: err.message }, { status: 500 });
  }
}

import { NextRequest, NextResponse } from 'next/server';
import { db } from '@/lib/db';
import { convert, type Currency } from '@/lib/currency';
import { requireAuth } from '@/lib/auth';

export async function GET(req: NextRequest) {
  try {
    const userId = requireAuth(req);
    const url = new URL(req.url);
    const where: any = { userId };
    const type = url.searchParams.get('type');
    const accountId = url.searchParams.get('accountId');
    const categoryId = url.searchParams.get('categoryId');
    const from = url.searchParams.get('from');
    const to = url.searchParams.get('to');
    const limit = url.searchParams.get('limit');
    if (type) where.type = type;
    if (accountId) where.accountId = accountId;
    if (categoryId) where.categoryId = categoryId;
    if (from || to) {
      where.date = {};
      if (from) where.date.gte = new Date(from);
      if (to) where.date.lte = new Date(to);
    }
    const transactions = await db.transaction.findMany({
      where,
      include: { account: true, category: true, toAccount: true },
      orderBy: { date: 'desc' },
      ...(limit ? { take: Math.max(1, Math.min(parseInt(limit, 10) || 100, 1000)) } : {}),
    });
    return NextResponse.json({ data: transactions });
  } catch (err: any) {
    if (err.message === 'Unauthorized') return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });
    return NextResponse.json({ error: err.message }, { status: 500 });
  }
}

export async function POST(req: NextRequest) {
  try {
    const userId = requireAuth(req);
    const body = await req.json();
    const { type, amount, currency, accountId, categoryId, date, note, tags } = body;

    // Validate input
    if (!type || !['EXPENSE', 'INCOME'].includes(type)) {
      return NextResponse.json({ error: 'Type must be EXPENSE or INCOME' }, { status: 400 });
    }
    const amt = Number(amount);
    if (!amt || amt <= 0 || !isFinite(amt)) {
      return NextResponse.json({ error: 'Amount must be positive number' }, { status: 400 });
    }
    if (!accountId || !categoryId) {
      return NextResponse.json({ error: 'accountId and categoryId required' }, { status: 400 });
    }

    // Verify BOTH account AND category ownership
    const [account, category] = await Promise.all([
      db.account.findFirst({ where: { id: accountId, userId } }),
      db.category.findFirst({ where: { id: categoryId, userId } }),
    ]);
    if (!account) return NextResponse.json({ error: 'Account not found' }, { status: 404 });
    if (!category) return NextResponse.json({ error: 'Category not found' }, { status: 404 });

    // Verify category type matches transaction type
    if (category.type !== type) {
      return NextResponse.json({ error: `Category type mismatch: category is ${category.type}, transaction is ${type}` }, { status: 400 });
    }

    const txCurrency = (currency || account.currency) as Currency;
    const amountInAccountCurrency = txCurrency === account.currency
      ? amt : convert(amt, txCurrency, account.currency as Currency);
    const delta = type === 'INCOME' ? amountInAccountCurrency : -amountInAccountCurrency;

    // ATOMIC
    const transaction = await db.$transaction(async (tx) => {
      await tx.account.update({ where: { id: accountId }, data: { balance: { increment: delta } } });
      return tx.transaction.create({
        data: { type, amount: amt, currency: txCurrency, accountId, categoryId, userId,
          date: date ? new Date(date) : new Date(), note: note || null, tags: tags || null },
        include: { account: true, category: true },
      });
    });
    return NextResponse.json({ data: transaction });
  } catch (err: any) {
    if (err.message === 'Unauthorized') return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });
    return NextResponse.json({ error: err.message }, { status: 500 });
  }
}

import { NextRequest, NextResponse } from 'next/server';
import { db } from '@/lib/db';
import { convert, type Currency } from '@/lib/currency';
import { requireAuth } from '@/lib/auth';

export async function POST(req: NextRequest) {
  try {
    const userId = requireAuth(req);
    const body = await req.json();
    const { fromAccountId, toAccountId, amount, currency, date, note } = body;

    if (!fromAccountId || !toAccountId || !amount || fromAccountId === toAccountId) {
      return NextResponse.json({ error: 'Invalid transfer parameters' }, { status: 400 });
    }

    const amt = Number(amount);
    if (amt <= 0) return NextResponse.json({ error: 'Amount must be positive' }, { status: 400 });

    // Verify both accounts belong to user
    const [sourceAccount, destAccount] = await Promise.all([
      db.account.findFirst({ where: { id: fromAccountId, userId } }),
      db.account.findFirst({ where: { id: toAccountId, userId } }),
    ]);
    if (!sourceAccount) return NextResponse.json({ error: 'Source account not found' }, { status: 404 });
    if (!destAccount) return NextResponse.json({ error: 'Destination account not found' }, { status: 404 });

    const txCurrency = (currency || sourceAccount.currency) as Currency;
    const sourceAmount = txCurrency === sourceAccount.currency
      ? amt : convert(amt, txCurrency, sourceAccount.currency as Currency);
    const destAmount = txCurrency === destAccount.currency
      ? amt : convert(amt, txCurrency, destAccount.currency as Currency);

    // ATOMIC: update both balances + create transaction
    let transferCat = await db.category.findFirst({ where: { nameAr: 'تحويلات', userId } });
    if (!transferCat) {
      transferCat = await db.category.create({
        data: { nameAr: 'تحويلات', nameEn: 'Transfers', type: 'EXPENSE', icon: 'arrow-right-left', color: '#64748B', userId },
      });
    }

    const transfer = await db.$transaction(async (tx) => {
      await tx.account.update({ where: { id: fromAccountId }, data: { balance: { increment: -sourceAmount } } });
      await tx.account.update({ where: { id: toAccountId }, data: { balance: { increment: destAmount } } });

      return tx.transaction.create({
        data: {
          type: 'TRANSFER' as any,
          amount: amt,
          currency: txCurrency,
          accountId: fromAccountId,
          categoryId: transferCat!.id,
          toAccountId: toAccountId,
          userId,
          date: date ? new Date(date) : new Date(),
          note: note || `تحويل من ${sourceAccount.name} إلى ${destAccount.name}`,
        },
        include: { account: true, category: true, toAccount: true },
      });
    });

    return NextResponse.json({ data: transfer });
  } catch (err: any) {
    if (err.message === 'Unauthorized') return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });
    console.error('Transfer error:', err);
    return NextResponse.json({ error: err.message }, { status: 500 });
  }
}

import { NextRequest, NextResponse } from 'next/server';
import { db } from '@/lib/db';
import { EXCHANGE_RATES, type Currency } from '@/lib/currency';
import { requireAuth } from '@/lib/auth';

// GET /api/stats?month=YYYY-MM&baseCurrency=EGP
export async function GET(req: NextRequest) {
  try {
    const userId = requireAuth(req);
    const url = new URL(req.url);
    const month = url.searchParams.get('month');
    const baseCurrency = (url.searchParams.get('baseCurrency') || 'EGP') as Currency;

    let start: Date, end: Date;
    if (month) {
      start = new Date(`${month}-01T00:00:00.000Z`);
      end = new Date(start);
      end.setMonth(end.getMonth() + 1);
    } else {
      start = new Date();
      start.setDate(1);
      start.setHours(0, 0, 0, 0);
      end = new Date(start);
      end.setMonth(end.getMonth() + 1);
    }

    const transactions = await db.transaction.findMany({
      where: { date: { gte: start, lt: end }, userId },
      include: { category: true, account: true },
    });

    const accounts = await db.account.findMany({ where: { userId } });

    const toBase = (amount: number, from: string) => {
      const fromCur = (from as Currency) || 'EGP';
      if (fromCur === baseCurrency) return amount;
      const inEgp = amount * EXCHANGE_RATES[fromCur];
      return inEgp / EXCHANGE_RATES[baseCurrency];
    };

    // Exclude transfers from BOTH expense and income
    const isTransfer = (t: any) =>
      t.type === 'TRANSFER' ||
      t.category?.nameAr === 'تحويلات' ||
      t.category?.nameEn === 'Transfers';

    const expenses = transactions.filter(t => t.type === 'EXPENSE' && !isTransfer(t));
    const incomes = transactions.filter(t => t.type === 'INCOME' && !isTransfer(t));

    const totalExpense = expenses.reduce((s, t) => s + toBase(t.amount, t.currency), 0);
    const totalIncome = incomes.reduce((s, t) => s + toBase(t.amount, t.currency), 0);

    // Total assets: exclude LOAN type
    const totalAssets = accounts
      .filter(a => a.type !== 'LOAN')
      .reduce((s, a) => s + toBase(a.balance, a.currency), 0);
    const totalLiabilities = accounts
      .filter(a => a.type === 'LOAN' && a.balance < 0)
      .reduce((s, a) => s + Math.abs(toBase(a.balance, a.currency)), 0);

    const byCategoryMap: Record<string, { total: number; count: number; category: any }> = {};
    expenses.forEach(t => {
      const cid = t.categoryId;
      if (!byCategoryMap[cid]) byCategoryMap[cid] = { total: 0, count: 0, category: t.category };
      byCategoryMap[cid].total += toBase(t.amount, t.currency);
      byCategoryMap[cid].count += 1;
    });

    // Daily chart: exclude transfers
    const daysInMonth = new Date(end.getFullYear(), end.getMonth(), 0).getDate();
    const byDay: { date: string; expense: number; income: number }[] = [];
    for (let day = 1; day <= daysInMonth; day++) {
      const dateStr = `${month || start.toISOString().slice(0, 7)}-${String(day).padStart(2, '0')}`;
      byDay.push({ date: dateStr, expense: 0, income: 0 });
    }
    transactions.forEach(t => {
      if (isTransfer(t)) return; // Exclude transfers from daily chart too
      const day = t.date.getDate();
      const idx = day - 1;
      if (idx >= 0 && idx < byDay.length) {
        if (t.type === 'EXPENSE') byDay[idx].expense += toBase(t.amount, t.currency);
        else if (t.type === 'INCOME') byDay[idx].income += toBase(t.amount, t.currency);
      }
    });

    return NextResponse.json({
      data: {
        totalExpense,
        totalIncome,
        balance: totalIncome - totalExpense,
        totalAssets,
        totalLiabilities,
        net: totalAssets - totalLiabilities,
        baseCurrency,
        expenseCount: expenses.length,
        incomeCount: incomes.length,
        byCategory: Object.values(byCategoryMap).sort((a: any, b: any) => b.total - a.total),
        byDay,
        month: month || start.toISOString().slice(0, 7),
      },
    });
  } catch (err: any) {
    if (err.message === 'Unauthorized') return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });
    console.error('GET /api/stats error:', err);
    return NextResponse.json({ error: err.message }, { status: 500 });
  }
}

import { NextRequest, NextResponse } from 'next/server';

export async function GET(req: NextRequest) {
  try {
    const userId = requireAuth(req);
    const url = new URL(req.url);
    const month = url.searchParams.get('month');
    const where: any = { userId };
    if (month) where.month = month;
    const budgets = await db.budget.findMany({ where, include: { category: true } });
    if (month) {
      const start = new Date(`${month}-01T00:00:00.000Z`);
      const end = new Date(start); end.setMonth(end.getMonth() + 1);
      const spent = await db.transaction.groupBy({
        by: ['categoryId'], where: { type: 'EXPENSE', date: { gte: start, lt: end }, userId },
        _sum: { amount: true },
      });
      const spentMap = new Map(spent.map(s => [s.categoryId, s._sum.amount || 0]));
      return NextResponse.json({ data: budgets.map(b => ({ ...b, spent: spentMap.get(b.categoryId) || 0 })) });
    }
    return NextResponse.json({ data: budgets });
  } catch (err: any) {
    if (err.message === 'Unauthorized') return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });
    return NextResponse.json({ error: err.message }, { status: 500 });
  }
}

export async function POST(req: NextRequest) {

    const userId = requireAuth(req);
    const body = await req.json();

      return NextResponse.json({ error: 'categoryId, month, limit required' }, { status: 400 });

    const limitNum = Number(limit);
    if (!limitNum || limitNum <= 0 || !isFinite(limitNum)) {
      return NextResponse.json({ error: 'limit must be positive' }, { status: 400 });

  } catch (err: any) {

      });
      catByArName.set(created.nameAr, created);
      return created;
    };

    let imported = 0, skipped = 0;
    for (const row of rows) {
      try {
        const keys = Object.keys(row);
        const findKey = (patterns: string[]) => {
          for (const p of patterns) {
            const k = keys.find(k => k.toLowerCase().trim().includes(p.toLowerCase()));
            if (k) return k;
          }
          return undefined;
        };

        const dateKey = findKey(['date', 'تاريخ']);

        const typeKey = findKey(['income/expense', 'نوع', 'type']);
        const amountKey = findKey(['sar', 'amount', 'مبلغ', 'value']);
        const currencyKey = findKey(['currency', 'عملة']);
        const noteKey = findKey(['note', 'ملاحظة', 'description']);

        let date: Date = new Date();
        if (dateKey) {
          const dv = row[dateKey];
          if (dv instanceof Date) date = dv;
          else if (typeof dv === 'number') date = new Date((Math.floor(dv) - 25569) * 86400 * 1000);
          else if (typeof dv === 'string') {
            const str = dv.trim();
            if (/^\d{1,2}\/\d{1,2}\/\d{4}$/.test(str)) {
              const [dd, mm, yyyy] = str.split('/');
              date = new Date(`${yyyy}-${mm.padStart(2, '0')}-${dd.padStart(2, '0')}`);
            } else date = new Date(str);
          }
        }

        const amount = amountKey ? parseFloat(String(row[amountKey])) || 0 : 0;
        if (!amount) { skipped++; continue; }

        const accName = accountKey ? String(row[accountKey] || '').trim() : '';
        if (!accName) { skipped++; continue; }
        const account = await ensureAccount(accName);
        if (!account) { skipped++; continue; }

        const catName = catKey ? String(row[catKey] || '').trim() : '';
        const rowType = (typeKey ? String(row[typeKey] || 'Expense') : 'Expense').toLowerCase();
        const category = await ensureCategory(catName, rowType, amount);
        if (!category) { skipped++; continue; }

        const currency = (currencyKey ? String(row[currencyKey] || 'SAR') : 'SAR').toUpperCase();
        const note = noteKey ? String(row[noteKey] || '') : '';

        const txType = rowType === 'income' || amount < 0 ? 'INCOME' : 'EXPENSE';
        const absAmount = Math.abs(amount);

        // ATOMIC: update balance + create transaction
        await db.$transaction(async (tx) => {
          const delta = txType === 'INCOME' ? absAmount : -absAmount;
          await tx.account.update({ where: { id: account.id }, data: { balance: { increment: delta } } });
          await tx.transaction.create({
            data: { type: txType, amount: absAmount, currency, accountId: account.id, categoryId: category.id, date, note: note || null, userId },
          });
        });

        imported++;
      } catch (e) { skipped++; }
    }

    return NextResponse.json({ success: true, imported, skipped, message: `Imported ${imported}, skipped ${skipped}` });
  } catch (err: any) {
    if (err.message === 'Unauthorized') return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });
    console.error('Excel import error:', err);
    return NextResponse.json({ error: err.message }, { status: 500 });
  }
}

    const budgetCount = await db.budget.count({ where: { userId } });

      }

      success: true,
      deleted: { transactions: txCount, budgets: budgetCount },
      message: `Deleted ${txCount} transactions, ${budgetCount} budgets. Accounts reset to 0. Categories kept.`,
    });
  } catch (err: any) {
    if (err.message === 'Unauthorized') return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });
    return NextResponse.json({ error: err.message }, { status: 500 });
  }

export function CategoriesScreen() {
  const { t, lang } = useT();
  const baseCurrency = useSettings(s => s.baseCurrency);
  const [items, setItems] = useState<TxItem[]>([]);
  const [loading, setLoading] = useState(true);
  const [range, setRange] = useState<RangeKey>('month');
  const [search, setSearch] = useState('');
  const [detailCatId, setDetailCatId] = useState<string | null>(null);

  const load = async () => {
    setLoading(true);
    try {
      const today = new Date().toISOString();
      const r = await api<{ data: TxItem[] }>(`/api/transactions?limit=9999&to=${today}`);
      setItems(r.data);
    } catch (e: any) { toast.error(e.message); }
    finally { setLoading(false); }
  };

  useEffect(() => { load(); }, []);

  // Date range filter
  const dateRange = useMemo(() => {
    const now = new Date();
    const end = now.toISOString().slice(0, 10);
    let start: string;
    switch (range) {
      case 'today': start = end; break;
      case 'week':
        const w = new Date(now); w.setDate(w.getDate() - 7);
        start = w.toISOString().slice(0, 10); break;
      case 'month':
        start = `${now.getFullYear()}-${String(now.getMonth() + 1).padStart(2, '0')}-01`; break;
      case 'year':
        start = `${now.getFullYear()}-01-01`; break;
    }
    return { start, end };
  }, [range]);

  // Filter + group by category
  const categoryTotals = useMemo(() => {
    const map = new Map<string, { category: Category; total: number; count: number }>();
    items.forEach(tx => {
      if (tx.type === 'TRANSFER' || tx.category.nameAr === 'تحويلات' || tx.category.nameEn === 'Transfers') return; // Skip transfers
      const txDate = new Date(tx.date).toISOString().slice(0, 10);
      if (txDate < dateRange.start || txDate > dateRange.end) return;
      if (search) {
        const q = search.toLowerCase();
        const name = (lang === 'ar' ? tx.category.nameAr : tx.category.nameEn).toLowerCase();
        if (!name.includes(q)) return;
      }
      const cid = tx.category.id;
      if (!map.has(cid)) map.set(cid, { category: tx.category, total: 0, count: 0 });
      const entry = map.get(cid)!;
      entry.total += convert(tx.amount, tx.currency as Currency, baseCurrency);
      entry.count += 1;
    });
    return Array.from(map.values()).sort((a, b) => b.total - a.total);
  }, [items, dateRange, search, baseCurrency, lang]);

  const totalExpense = categoryTotals
    .filter(c => c.category.type === 'EXPENSE' || c.category.type === 'TRANSFER')

      </header>

      {/* Range filter */}
      <div className="flex gap-1 bg-slate-100 dark:bg-slate-800 rounded-lg p-1">
        {(Object.keys(rangeLabels) as RangeKey[]).map(k => (
          <button
            key={k}
            onClick={() => setRange(k)}
            className={cn(
              'flex-1 py-1.5 rounded text-xs font-medium transition',
              range === k ? 'bg-white dark:bg-slate-900 text-blue-700 dark:text-blue-300 shadow-sm' : 'text-slate-500'
            )}
          >
            {rangeLabels[k]}
          </button>
        ))}
      </div>

      {/* Search */}
      <div className="relative">
        <Search className="absolute start-3 top-1/2 -translate-y-1/2 w-4 h-4 text-slate-400" />
        <Input value={search} onChange={e => setSearch(e.target.value)} placeholder={lang === 'ar' ? 'بحث فئة...' : 'Search...'} className="ps-9" />

  { type: 'LOAN', arLabel: 'قروض وسلف', enLabel: 'Loans', icon: 'hand-coins', isAsset: false },
];

const ICONS = ['wallet', 'credit-card', 'landmark', 'smartphone', 'piggy-bank', 'banknote',
  'trending-up', 'gem', 'bitcoin', 'diamond', 'home', 'car', 'plane', 'gift',
  'shield', 'briefcase', 'building-2', 'coin', 'dollar-sign', 'euro', 'pound-sterling'];
const COLORS = ['#2563EB', '#10B981', '#F59E0B', '#EF4444', '#8B5CF6', '#06B6D4',
  '#EC4899', '#14B8A6', '#F97316', '#84CC16', '#A855F7', '#0EA5E9'];

const TYPES = [
  { value: 'CASH', labelAr: 'نقدي', labelEn: 'Cash' },
  { value: 'BANK', labelAr: 'بنك', labelEn: 'Bank' },
  { value: 'E_WALLET', labelAr: 'محفظة إلكترونية', labelEn: 'E-Wallet' },
  { value: 'CARD', labelAr: 'بطاقة ائتمان', labelEn: 'Credit Card' },
  { value: 'SAVINGS', labelAr: 'حساب توفير', labelEn: 'Savings' },

  { value: 'EXTERNAL', labelAr: 'حساب خارجي', labelEn: 'External' },
];

const CURRENCIES: { value: Currency; label: string }[] = [
  { value: 'EGP', label: 'EGP' },
  { value: 'SAR', label: 'SAR' },
  { value: 'USD', label: 'USD' },
  { value: 'EUR', label: 'EUR' },
  { value: 'AED', label: 'AED' },
];

export function AccountsScreen() {
  const { t, lang } = useT();
  const baseCurrency = useSettings(s => s.baseCurrency);
  const [accounts, setAccounts] = useState<Account[]>([]);
  const [loading, setLoading] = useState(true);
  const [modal, setModal] = useState<{ open: boolean; data?: Account | null }>({ open: false });
  const [search, setSearch] = useState('');
  const [detailAccountId, setDetailAccountId] = useState<string | null>(null);

  const load = async () => {
    setLoading(true);
    try {
      const r = await api<{ data: Account[] }>('/api/accounts');
      setAccounts(r.data);
    } catch (e: any) {
      toast.error(e.message);
    } finally { setLoading(false); }
  };

  useEffect(() => { load(); }, []);

  // Convert balance to display currency
  const convertToBase = (balance: number, fromCurrency: string) =>
    convert(balance, fromCurrency as Currency, baseCurrency);

  // Filter accounts by search
  const filteredAccounts = accounts.filter(a => {
    if (!search) return true;
    const q = search.toLowerCase();
    return a.name.toLowerCase().includes(q) ||
      a.currency.toLowerCase().includes(q) ||
      a.type.toLowerCase().includes(q);
  });

  // Group accounts
  const groupedAccounts = ACCOUNT_GROUPS.map(group => ({
    ...group,
    accounts: filteredAccounts.filter(a => a.type === group.type),
  })).filter(g => g.accounts.length > 0);

  // Calculate totals
  const totalAssets = accounts
    .filter(a => !['LOAN'].includes(a.type))
    .reduce((s, a) => s + convertToBase(a.balance, a.currency), 0);
  const totalLiabilities = accounts
    .filter(a => a.type === 'LOAN' && a.balance < 0)
    .reduce((s, a) => s + Math.abs(convertToBase(a.balance, a.currency)), 0);
  const net = totalAssets - totalLiabilities;

  const fmt = (n: number, cur: Currency = baseCurrency) => formatMoney(n, cur, lang);

  const handleSave = async (data: any) => {
    try {
      if (data.id) {
        await api(`/api/accounts/${data.id}`, { method: 'PUT', body: JSON.stringify(data) });
        toast.success(lang === 'ar' ? 'تم التعديل' : 'Updated');
      } else {
        await api('/api/accounts', { method: 'POST', body: JSON.stringify(data) });
        toast.success(lang === 'ar' ? 'تم الإضافة' : 'Created');
      }
      setModal({ open: false });
      load();
    } catch (e: any) {
      toast.error(e.message);
    }
  };

  const handleDelete = async (id: string) => {
    if (!confirm(lang === 'ar' ? 'حذف الحساب؟' : 'Delete account?')) return;
    try {
      await api(`/api/accounts/${id}`, { method: 'DELETE' });
      toast.success(lang === 'ar' ? 'تم الحذف' : 'Deleted');
      load();
    } catch (e: any) {
      toast.error(e.message);
    }
  };

  if (loading) {
    return (
      <div className="p-4 space-y-3">
        <Skeleton className="h-32 w-full rounded-2xl" />
        {Array.from({ length: 3 }).map((_, i) => <Skeleton key={i} className="h-20 w-full rounded-xl" />)}
      </div>
    );
  }

  return (
    <div className="p-4 space-y-5 pb-4">
      <header className="flex justify-between items-center">
        <div>
          <h1 className="text-2xl font-bold">{t('accounts')}</h1>
          <p className="text-xs text-slate-500">{accounts.length} {t('accounts')}</p>
        </div>
        <Button onClick={() => setModal({ open: true })} size="sm" className="rounded-full bg-blue-600 hover:bg-blue-700">
          <Plus className="w-4 h-4" /> {t('add')}
        </Button>
      </header>

      {/* Search box */}
      <div className="relative">
        <Search className="absolute start-3 top-1/2 -translate-y-1/2 w-4 h-4 text-slate-400" />
        <Input
          value={search}
          onChange={e => setSearch(e.target.value)}
          placeholder={lang === 'ar' ? 'بحث بالاسم أو العملة...' : 'Search by name or currency...'}
          className="ps-9"
        />
      </div>

      {/* Summary Card: Assets / Liabilities / Net */}
      <div className="grid grid-cols-3 gap-2">
        <Card className="p-3 bg-emerald-50 dark:bg-emerald-950/30 border-emerald-200 dark:border-emerald-900">
          <div className="flex items-center gap-1.5 mb-1">
            <TrendingUp className="w-3.5 h-3.5 text-emerald-600" />
            <span className="text-[10px] font-semibold text-emerald-700 dark:text-emerald-400">
              {lang === 'ar' ? 'الأصول' : 'Assets'}
            </span>
          </div>
          <p className="text-sm font-bold text-emerald-700 dark:text-emerald-300 truncate">{fmt(totalAssets)}</p>
        </Card>
        <Card className="p-3 bg-red-50 dark:bg-red-950/30 border-red-200 dark:border-red-900">
          <div className="flex items-center gap-1.5 mb-1">
            <TrendingDown className="w-3.5 h-3.5 text-red-600" />
            <span className="text-[10px] font-semibold text-red-700 dark:text-red-400">
              {lang === 'ar' ? 'الخصوم' : 'Liabilities'}
            </span>
          </div>
          <p className="text-sm font-bold text-red-700 dark:text-red-300 truncate">{fmt(totalLiabilities)}</p>
        </Card>
        <Card className="p-3 bg-blue-50 dark:bg-blue-950/30 border-blue-200 dark:border-blue-900">
          <div className="flex items-center gap-1.5 mb-1">
            <Wallet className="w-3.5 h-3.5 text-blue-600" />
            <span className="text-[10px] font-semibold text-blue-700 dark:text-blue-400">
              {lang === 'ar' ? 'الصافي' : 'Net'}
            </span>
          </div>
          <p className={cn("text-sm font-bold truncate", net >= 0 ? "text-blue-700 dark:text-blue-300" : "text-red-700 dark:text-red-300")}>
            {fmt(net)}
          </p>
        </Card>
      </div>

      {/* Grouped accounts */}
      {groupedAccounts.map(group => {
        const groupTotal = group.accounts.reduce(
          (s, a) => s + convertToBase(a.balance, a.currency),
          0
        );
        const GroupIcon = getIcon(group.icon);
        return (
          <div key={group.type} className="space-y-2">
            {/* Group header */}
            <div className="flex items-center justify-between px-1">
              <div className="flex items-center gap-2">
                <div className={cn(
                  "w-7 h-7 rounded-lg flex items-center justify-center text-white",
                  group.isAsset ? "bg-blue-600" : "bg-red-600"
                )}>
                  <GroupIcon className="w-4 h-4" />
                </div>
                <h3 className="text-sm font-semibold">{lang === 'ar' ? group.arLabel : group.enLabel}</h3>
                <span className="text-xs text-slate-400">({group.accounts.length})</span>
              </div>
              <span className={cn(
                "text-xs font-semibold",
                groupTotal >= 0 ? "text-slate-600 dark:text-slate-300" : "text-red-600 dark:text-red-400"
              )}>
                {fmt(groupTotal)}
              </span>
            </div>

            {/* Accounts in this group */}
            <Card className="divide-y divide-slate-100 dark:divide-slate-800 overflow-hidden">
              {group.accounts.map(a => {
                const Icon = getIcon(a.icon);
                const isNegative = a.balance < 0;
                return (
                  <div key={a.id} className="flex items-center gap-3 p-3 hover:bg-slate-50 dark:hover:bg-slate-800/50 transition">
                    <button
                      onClick={() => setDetailAccountId(a.id)}
                      className="flex items-center gap-3 flex-1 min-w-0 text-start"
                    >
                      <div
                        className="w-10 h-10 rounded-xl flex items-center justify-center text-white shrink-0"
                        style={{ background: a.color }}
                      >
                        <Icon className="w-5 h-5" />
                      </div>
                      <div className="flex-1 min-w-0">
                        <div className="flex items-center gap-1.5">
                          <p className="font-medium text-sm truncate">{a.name}</p>
                          {a.isDefault && (
                            <span className="text-[10px] bg-blue-100 text-blue-700 px-1.5 py-0.5 rounded-full shrink-0">
                              {t('default')}
                            </span>
                          )}
                        </div>
                        <p className="text-xs text-slate-400">
                          {a.currency} • {TYPES.find(t => t.value === a.type)?.[lang === 'ar' ? 'labelAr' : 'labelEn']}
                        </p>
                      </div>
                    </button>
                    <div className="text-end shrink-0">
                      <p className={cn(
                        "font-bold text-sm",
                        isNegative ? "text-red-600 dark:text-red-400" : "text-slate-900 dark:text-slate-100"
                      )}>
                        {formatMoney(a.balance, a.currency as Currency, lang)}
                      </p>
                      {a.currency !== baseCurrency && (
                        <p className="text-[10px] text-slate-400">≈ {fmt(convertToBase(a.balance, a.currency))}</p>
                      )}
                    </div>
                    <button
                      onClick={(e) => { e.stopPropagation(); setModal({ open: true, data: a }); }}
                      className="p-1.5 text-slate-300 hover:text-blue-600 shrink-0"
                      aria-label={t('edit')}
                    >
                      <Pencil className="w-4 h-4" />
                    </button>
                    <button
                      onClick={() => handleDelete(a.id)}
                      className="p-1.5 text-slate-300 hover:text-red-500 shrink-0"
                      aria-label={t('delete')}
                    >
                      <Trash2 className="w-4 h-4" />
                    </button>
                  </div>
                );
              })}
            </Card>
          </div>
        );
      })}

      {/* Empty state */}
      {accounts.length === 0 && (
        <Card className="p-8 text-center">
          <Wallet className="w-12 h-12 mx-auto text-slate-300 mb-2" />
          <p className="text-sm text-slate-500">
            {lang === 'ar' ? 'لا توجد حسابات بعد. اضغط زر + لإضافة حساب جديد.' : 'No accounts yet. Tap + to add one.'}
          </p>
        </Card>
      )}

      <AccountModal
        key={modal.data?.id || 'new'}
        open={modal.open}
        onOpenChange={o => setModal(m => ({ ...m, open: o }))}
        initial={modal.data}
        onSave={handleSave}
      />

      {/* Account detail dialog */}
      {detailAccountId && (
        <AccountDetailModal
          accountId={detailAccountId}
          onClose={() => setDetailAccountId(null)}
          onEditTx={() => {/* TODO: implement edit from detail */}}
        />
      )}
    </div>
  );
}

/** Account detail view - shows account info + recent transactions */
function AccountDetailModal({
  accountId,
  onClose,
  onEditTx,
}: {
  accountId: string;
  onClose: () => void;
  onEditTx?: (tx: any) => void;
}) {
  const { t, lang } = useT();
  const baseCurrency = useSettings(s => s.baseCurrency);
  const [account, setAccount] = useState<Account | null>(null);
  const [transactions, setTransactions] = useState<any[]>([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    Promise.all([
      api<{ data: Account[] }>('/api/accounts'),
      api<{ data: any[] }>(`/api/transactions?accountId=${accountId}&limit=200`),
    ]).then(([accs, txs]) => {
      const acc = accs.data.find(a => a.id === accountId) || null;
      setAccount(acc);
      setTransactions(txs.data);
    }).finally(() => setLoading(false));
  }, [accountId]);

  const fmt = (n: number, cur: any = baseCurrency) => formatMoney(n, cur, lang);
  const convertToBase = (balance: number, fromCurrency: string) =>
    convert(balance, fromCurrency as Currency, baseCurrency);

  // Calculate totals for this account
  const totalIncome = transactions
    .filter(t => t.type === 'INCOME')
    .reduce((s, t) => s + convertToBase(t.amount, t.currency), 0);
  const totalExpense = transactions
    .filter(t => t.type === 'EXPENSE')
    .reduce((s, t) => s + convertToBase(t.amount, t.currency), 0);
  const totalTransfers = transactions
    .filter(t => t.type === 'TRANSFER')
    .reduce((s, t) => s + convertToBase(t.amount, t.currency), 0);

  return (
    <Dialog open={true} onOpenChange={(o) => !o && onClose()}>
      <DialogContent className="max-w-md max-h-[90vh] overflow-y-auto">
        <DialogHeader>
          <DialogTitle className="flex items-center gap-2">
            {account && (
              <>
                <div
                  className="w-8 h-8 rounded-lg flex items-center justify-center text-white"
                  style={{ background: account.color }}
                >
                  {(() => {
                    const I = getIcon(account.icon);
                    return <I className="w-4 h-4" />;
                  })()}
                </div>
                {account.name}
              </>
            )}
          </DialogTitle>
        </DialogHeader>

        {loading ? (
          <div className="py-8 text-center">
            <Skeleton className="h-32 w-full" />
          </div>
        ) : account ? (
          <>
            {/* Account balance */}
            <Card className="p-5 bg-gradient-to-br from-blue-600 to-blue-700 text-white border-0">
              <p className="text-xs text-blue-100">{lang === 'ar' ? 'الرصيد الحالي' : 'Current Balance'}</p>
              <p className="text-3xl font-bold mt-1">
                {formatMoney(account.balance, account.currency as Currency, lang)}
              </p>
              {account.currency !== baseCurrency && (
                <p className="text-xs text-blue-200 mt-1">
                  ≈ {fmt(convertToBase(account.balance, account.currency))}
                </p>
              )}
            </Card>

            {/* Mini summary */}
            <div className="grid grid-cols-3 gap-2 mt-2">
              <div className="p-2 rounded-lg bg-emerald-50 dark:bg-emerald-950/30 text-center">
                <p className="text-[10px] text-emerald-700 dark:text-emerald-400">{lang === 'ar' ? 'دخل' : 'Income'}</p>
                <p className="text-xs font-bold text-emerald-700 dark:text-emerald-300 truncate">{fmt(totalIncome)}</p>
              </div>
              <div className="p-2 rounded-lg bg-red-50 dark:bg-red-950/30 text-center">
                <p className="text-[10px] text-red-700 dark:text-red-400">{lang === 'ar' ? 'مصروف' : 'Expense'}</p>
                <p className="text-xs font-bold text-red-700 dark:text-red-300 truncate">{fmt(totalExpense)}</p>
              </div>
              <div className="p-2 rounded-lg bg-slate-50 dark:bg-slate-800/50 text-center">
                <p className="text-[10px] text-slate-700 dark:text-slate-300">{lang === 'ar' ? 'تحويل' : 'Transfer'}</p>
                <p className="text-xs font-bold text-slate-700 dark:text-slate-300 truncate">{fmt(totalTransfers)}</p>
              </div>
            </div>

            {/* Transactions list */}
            <div className="mt-4">
              <h3 className="text-sm font-semibold mb-2">
                {transactions.length} {lang === 'ar' ? 'معاملة' : 'transactions'}
              </h3>
              <div className="max-h-72 overflow-y-auto -mx-2">
                {transactions.length === 0 ? (
                  <p className="text-center text-sm text-slate-400 py-4">{t('noTransactionsYet')}</p>
                ) : (
                  transactions.slice(0, 50).map(tx => {
                    const Icon = getIcon(tx.category?.icon || 'tag');
                    const isIncome = tx.type === 'INCOME';
                    const isTransfer = tx.type === 'TRANSFER';
                    return (
                      <div key={tx.id} className="flex items-center gap-3 p-2 hover:bg-slate-50 dark:hover:bg-slate-800/50 rounded-lg transition">
                        <div
                          className="w-8 h-8 rounded-full flex items-center justify-center text-white shrink-0"
                          style={{ background: isTransfer ? '#64748B' : tx.category?.color || '#64748B' }}
                        >
                          <Icon className="w-4 h-4" />
                        </div>
                        <div className="flex-1 min-w-0">
                          <p className="text-sm font-medium truncate">
                            {isTransfer
                              ? (lang === 'ar' ? 'تحويل' : 'Transfer')
                              : (lang === 'ar' ? tx.category?.nameAr : tx.category?.nameEn)}
                          </p>
                          <p className="text-[10px] text-slate-400 truncate">
                            {new Date(tx.date).toLocaleDateString(lang === 'ar' ? 'ar-EG' : 'en-US', { day: 'numeric', month: 'short', year: 'numeric' })}
                            {tx.note ? ` • ${tx.note}` : ''}
                          </p>
                        </div>
                        <span className={cn(
                          'text-xs font-semibold shrink-0',
                          isIncome
                            ? 'text-emerald-600 dark:text-emerald-400'
                            : isTransfer
                              ? 'text-slate-600 dark:text-slate-300'
                              : 'text-red-600 dark:text-red-400'
                        )}>
                          {isIncome ? '+' : isTransfer ? '⇄ ' : '-'}{fmt(tx.amount, tx.currency)}
                        </span>
                      </div>
                    );
                  })
                )}
              </div>
            </div>
          </>
        ) : (
          <p className="text-center text-sm text-slate-400 py-4">{lang === 'ar' ? 'الحساب غير موجود' : 'Account not found'}</p>
        )}
      </DialogContent>
    </Dialog>
  );
}

function AccountModal({
  open, onOpenChange, initial, onSave,
}: {
  open: boolean;
  onOpenChange: (o: boolean) => void;
  initial?: Account | null;
  onSave: (data: any) => void;
}) {
  const { t, lang } = useT();
  const [name, setName] = useState(initial?.name || '');
  const [type, setType] = useState(initial?.type || 'CASH');
  const [currency, setCurrency] = useState<Currency>(initial?.currency as Currency || 'EGP');
  const [balance, setBalance] = useState(initial ? initial.balance.toString() : '');
  const [color, setColor] = useState(initial?.color || COLORS[0]);
  const [icon, setIcon] = useState(initial?.icon || 'wallet');
  const [isDefault, setIsDefault] = useState(initial?.isDefault || false);

  const submit = () => {
    if (!name || !type || !currency) {
      toast.error(lang === 'ar' ? 'أدخل الاسم والنوع والعملة' : 'Enter name, type, currency');
      return;
    }
    onSave({
      id: initial?.id,
      name, type, currency,
      balance: parseFloat(balance) || 0,
      color, icon, isDefault,
    });
  };

  return (
    <Dialog open={open} onOpenChange={onOpenChange}>
      <DialogContent>
        <DialogHeader>
          <DialogTitle>{initial ? t('editAccount') : t('addAccount')}</DialogTitle>
        </DialogHeader>
        <div className="space-y-3 max-h-[70vh] overflow-y-auto">
          <div className="flex justify-center py-2">
            <div
              className="w-16 h-16 rounded-2xl flex items-center justify-center text-white"
              style={{ background: color }}
            >
              <DynamicIcon name={icon} className="w-7 h-7" />
            </div>
          </div>

          <div className="space-y-1.5">
            <Label>{t('account')}</Label>
            <Input value={name} onChange={e => setName(e.target.value)} placeholder="..." />
          </div>

          <div className="grid grid-cols-2 gap-2">
            <div className="space-y-1.5">
              <Label>{t('type')}</Label>
              <Select value={type} onValueChange={setType}>
                <SelectTrigger><SelectValue /></SelectTrigger>
                <SelectContent>
                  {TYPES.map(t => <SelectItem key={t.value} value={t.value}>{lang === 'ar' ? t.labelAr : t.labelEn}</SelectItem>)}
                </SelectContent>
              </Select>
            </div>
            <div className="space-y-1.5">
              <Label>{t('currency')}</Label>
              <Select value={currency} onValueChange={(v: any) => setCurrency(v)}>
                <SelectTrigger><SelectValue /></SelectTrigger>
                <SelectContent>
                  {CURRENCIES.map(c => <SelectItem key={c.value} value={c.value}>{c.label}</SelectItem>)}
                </SelectContent>
              </Select>
            </div>
          </div>

          <div className="space-y-1.5">
            <Label>{t('balance')}</Label>
            <Input type="number" inputMode="decimal" value={balance} onChange={e => setBalance(e.target.value)} placeholder="0.00" />
          </div>

          <div className="space-y-1.5">
            <Label>{lang === 'ar' ? 'اللون' : 'Color'}</Label>
            <div className="flex gap-2 flex-wrap">
              {COLORS.map(c => (
                <button
                  key={c}
                  onClick={() => setColor(c)}
                  className={cn(
                    'w-8 h-8 rounded-full border-2 transition',
                    color === c ? 'border-slate-900 dark:border-white scale-110' : 'border-transparent'
                  )}
                  style={{ background: c }}
                />
              ))}
            </div>
          </div>

          <div className="space-y-1.5">
            <Label>{lang === 'ar' ? 'الأيقونة' : 'Icon'}</Label>
            <div className="grid grid-cols-8 gap-1.5 max-h-44 overflow-y-auto p-1 border border-slate-200 dark:border-slate-800 rounded-lg">
              {ICONS.map(i => {
                const I = getIcon(i);
                const sel = icon === i;
                return (
                  <button
                    key={i}
                    type="button"
                    onClick={() => setIcon(i)}
                    className={cn(
                      'aspect-square rounded-lg flex items-center justify-center transition border-2',
                      sel
                        ? 'border-blue-500 bg-blue-50 dark:bg-blue-950'
                        : 'border-transparent hover:bg-slate-100 dark:hover:bg-slate-800'
                    )}
                    style={sel ? { color } : undefined}
                  >
                    <I className="w-4 h-4" />
                  </button>
                );
              })}
            </div>
          </div>

          <div className="flex items-center justify-between bg-slate-50 dark:bg-slate-800 p-3 rounded-xl">
            <Label htmlFor="default-toggle" className="cursor-pointer">{t('makeDefault')}</Label>
            <Switch id="default-toggle" checked={isDefault} onCheckedChange={setIsDefault} />
          </div>
        </div>
        <DialogFooter>
          <Button variant="outline" onClick={() => onOpenChange(false)}>{t('cancel')}</Button>

  const { t, lang } = useT();
  const baseCurrency = useSettings(s => s.baseCurrency);
  const [txs, setTxs] = useState<any[]>([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    const start = `${month}-01`;
    const end = new Date(start);
    end.setMonth(end.getMonth() + 1);
    api<{ data: any[] }>(`/api/transactions?categoryId=${categoryId}&from=${start}&to=${end.toISOString()}&limit=500`)
      .then(r => setTxs(r.data))
      .finally(() => setLoading(false));
  }, [categoryId, month]);

  const fmt = (n: number, cur: any = baseCurrency) => formatMoney(n, cur, lang);
  const total = txs.reduce((s, t) => s + convert(t.amount, t.currency as Currency, baseCurrency), 0);

  return (
    <Dialog open={true} onOpenChange={(o) => !o && onClose()}>
      <DialogContent className="max-w-md max-h-[90vh] overflow-y-auto">
        <DialogHeader>
          <DialogTitle>
            {txs[0] ? (lang === 'ar' ? txs[0].category.nameAr : txs[0].category.nameEn) : (lang === 'ar' ? 'تفاصيل الفئة' : 'Category Details')}
          </DialogTitle>
        </DialogHeader>
        {loading ? (
          <Skeleton className="h-40 w-full" />
        ) : (
          <>
            <Card className="p-4 bg-blue-600 text-white border-0">
              <p className="text-xs text-blue-100">{lang === 'ar' ? 'إجمالي الإنفاق' : 'Total Spending'}</p>
              <p className="text-2xl font-bold">{fmt(total)}</p>
              <p className="text-xs text-blue-200 mt-1">{txs.length} {lang === 'ar' ? 'معاملة' : 'transactions'}</p>
            </Card>
            <div className="mt-3 space-y-1.5 max-h-72 overflow-y-auto">
              {txs.map(tx => {
                const Icon = getIcon(tx.category?.icon || 'tag');
                const isIncome = tx.type === 'INCOME';
                return (
                  <div key={tx.id} className="flex items-center gap-2 p-2 hover:bg-slate-50 dark:hover:bg-slate-800/50 rounded-lg">
                    <div className="w-8 h-8 rounded-full flex items-center justify-center text-white shrink-0" style={{ background: tx.category?.color || '#64748B' }}>
                      <Icon className="w-4 h-4" />
                    </div>
                    <div className="flex-1 min-w-0">
                      <p className="text-sm font-medium truncate">{tx.account?.name}</p>
                      <p className="text-[10px] text-slate-400 truncate">
                        {new Date(tx.date).toLocaleDateString(lang === 'ar' ? 'ar-EG' : 'en-US', { day: 'numeric', month: 'short' })}
                        {tx.note ? ` • ${tx.note}` : ''}
                      </p>
                    </div>
                    <span className={cn('text-xs font-semibold shrink-0', isIncome ? 'text-emerald-600' : 'text-red-600')}>
                      {isIncome ? '+' : '-'}{fmt(tx.amount, tx.currency)}
                    </span>
                  </div>
                );
              })}
            </div>
          </>
        )}
      </DialogContent>
    </Dialog>
  );
}

import { Globe, Palette, Coins, Bell, Info, Download, RefreshCw, Smartphone } from 'lucide-react';
import { useT } from '@/hooks/use-t';
import { useSettings } from '@/lib/store';
import { api } from '@/lib/api';
import { toast } from 'sonner';
import { getStoredToken, setStoredToken } from '@/lib/auth-storage';
import type { Currency } from '@/lib/currency';
import { CategoriesManager } from '@/components/categories-manager';
import { DataTools } from '@/components/data-tools';

const CURRENCIES: Currency[] = ['EGP', 'SAR', 'USD', 'EUR', 'AED'];

export function SettingsScreen({ onLogout }: { onLogout?: () => void }) {
  const { t, lang } = useT();
  const { lang: curLang, setLang, baseCurrency, setBaseCurrency, theme, setTheme } = useSettings();
  const [notifications, setNotifications] = useState(true);
  const [installEvt, setInstallEvt] = useState<any>(null);
  const [canInstall, setCanInstall] = useState(false);

  useEffect(() => {
    const handler = (e: any) => {
      e.preventDefault();
      setInstallEvt(e);
      setCanInstall(true);
    };
    window.addEventListener('beforeinstallprompt', handler);
    return () => window.removeEventListener('beforeinstallprompt', handler);
  }, []);

  const handleInstall = async () => {
    if (!installEvt) {
      toast.info(lang === 'ar'
        ? 'استخدم قائمة المتصفح > Add to Home Screen'
        : 'Use browser menu > Add to Home Screen');
      return;
    }
    installEvt.prompt();
    await installEvt.userChoice;
    setCanInstall(false);
  };

  const handleReset = async () => {
    if (!confirm(t('confirmReset'))) return;
    try {
      const token = getStoredToken();
      const res = await fetch('/api/reset', {
        method: 'POST',
        headers: token ? { Authorization: `Bearer ${token}` } : {},
      });
      const data = await res.json();
      if (!res.ok) throw new Error(data.error);
      toast.success(lang === 'ar'
        ? `تم حذف ${data.deleted.transactions} معاملة و ${data.deleted.budgets} ميزانية`
        : `Deleted ${data.deleted.transactions} txns, ${data.deleted.budgets} budgets`);
      setTimeout(() => window.location.reload(), 1500);
    } catch (e: any) {
      toast.error(e.message);
    }
  };

  return (
    <div className="p-4 space-y-5">
      <header>
        <h1 className="text-2xl font-bold">{t('settings')}</h1>
        <p className="text-sm text-slate-500">{t('appName')}</p>
      </header>

      {/* Language */}
      <Card className="p-4">
        <div className="flex items-center gap-3 mb-3">
          <Globe className="w-5 h-5 text-blue-600" />
          <h2 className="font-semibold">{t('language')}</h2>
        </div>
        <div className="grid grid-cols-2 gap-2">
          <button
            onClick={() => setLang('ar')}
            className={`p-3 rounded-xl border-2 transition ${curLang === 'ar' ? 'border-blue-500 bg-blue-50 dark:bg-blue-950' : 'border-slate-200 dark:border-slate-800'}`}
          >
            <span className="text-2xl">🇪🇬</span>
            <p className="text-sm font-medium mt-1">{t('arabic')}</p>
          </button>
          <button
            onClick={() => setLang('en')}
            className={`p-3 rounded-xl border-2 transition ${curLang === 'en' ? 'border-blue-500 bg-blue-50 dark:bg-blue-950' : 'border-slate-200 dark:border-slate-800'}`}
          >
            <span className="text-2xl">🇬🇧</span>
            <p className="text-sm font-medium mt-1">{t('english')}</p>
          </button>
        </div>
      </Card>

      {/* Currency */}
      <Card className="p-4">
        <div className="flex items-center gap-3 mb-3">
          <Coins className="w-5 h-5 text-emerald-600" />
          <h2 className="font-semibold">{t('baseCurrency')}</h2>
        </div>
        <Select value={baseCurrency} onValueChange={(v: any) => setBaseCurrency(v)}>
          <SelectTrigger className="w-full"><SelectValue /></SelectTrigger>
          <SelectContent>
            {CURRENCIES.map(c => <SelectItem key={c} value={c}>{c}</SelectItem>)}
          </SelectContent>
        </Select>
      </Card>

      {/* Appearance */}
      <Card className="p-4">
        <div className="flex items-center gap-3 mb-3">
          <Palette className="w-5 h-5 text-purple-600" />
          <h2 className="font-semibold">{t('appearance')}</h2>
        </div>
        <div className="grid grid-cols-3 gap-2">
          {(['light', 'dark', 'system'] as const).map(th => (
            <button
              key={th}
              onClick={() => setTheme(th)}
              className={`p-3 rounded-xl border-2 transition text-sm font-medium ${theme === th ? 'border-blue-500 bg-blue-50 dark:bg-blue-950 text-blue-700 dark:text-blue-300' : 'border-slate-200 dark:border-slate-800'}`}
            >
              {th === 'light' ? t('light') : th === 'dark' ? t('dark') : t('system')}
            </button>
          ))}
        </div>
      </Card>

      {/* Notifications */}
      <Card className="p-4">
        <div className="flex items-center justify-between">
          <div className="flex items-center gap-3">
            <Bell className="w-5 h-5 text-amber-600" />
            <div>
              <h2 className="font-semibold">{t('notifications')}</h2>
              <p className="text-xs text-slate-500">{lang === 'ar' ? 'تنبيهات الميزانية' : 'Budget alerts'}</p>
            </div>
          </div>
          <Switch checked={notifications} onCheckedChange={setNotifications} />
        </div>
      </Card>

      {/* Install App */}
      <Card className="p-4">
        <div className="flex items-center gap-3 mb-3">
          <Smartphone className="w-5 h-5 text-blue-600" />
          <h2 className="font-semibold">{t('installApp')}</h2>
        </div>
        <p className="text-xs text-slate-500 mb-3">{t('installHint')}</p>
        <Button onClick={handleInstall} className="w-full" disabled={!canInstall && !installEvt}>
          <Download className="w-4 h-4" /> {canInstall ? t('installNow') : (lang === 'ar' ? 'غير متاح الآن' : 'Not available now')}
        </Button>
      </Card>

      {/* Download APK - Native Android App */}
      <Card className="p-4 border-2 border-blue-200 dark:border-blue-900 bg-gradient-to-br from-blue-50 to-white dark:from-blue-950/30 dark:to-slate-900">
        <div className="flex items-center gap-3 mb-3">
          <div className="w-10 h-10 rounded-xl bg-blue-600 flex items-center justify-center text-white shrink-0">
            <Download className="w-5 h-5" />
          </div>
          <div className="flex-1">
            <h2 className="font-semibold text-blue-900 dark:text-blue-100">
              {lang === 'ar' ? 'تحميل تطبيق Android (APK)' : 'Download Android App (APK)'}
            </h2>
            <p className="text-xs text-slate-500 mt-0.5">
              {lang === 'ar'
                ? 'حمّل ملف APK وثبّته على موبايلك بدون نشر على Google Play'
                : 'Download APK file and install on your phone without Google Play'}
            </p>
          </div>
        </div>
        <div className="text-xs text-slate-500 mb-3 space-y-1">
          <div className="flex items-center justify-between">
            <span>{lang === 'ar' ? 'الإصدار' : 'Version'}:</span>
            <span className="font-mono">1.0.0</span>
          </div>
          <div className="flex items-center justify-between">
            <span>{lang === 'ar' ? 'الحجم' : 'Size'}:</span>
            <span className="font-mono">5.5 MB</span>
          </div>
          <div className="flex items-center justify-between">
            <span>{lang === 'ar' ? 'يدعم' : 'Supports'}:</span>
            <span className="font-mono">Android 7.0+</span>
          </div>
        </div>
        <a
          href="/MyWallet.apk"
          download="MyWallet.apk"
          className="flex items-center justify-center gap-2 w-full h-12 rounded-xl bg-blue-600 hover:bg-blue-700 active:scale-95 transition text-white font-semibold text-base shadow-md"
        >
          <Download className="w-5 h-5" />
          {lang === 'ar' ? 'حمّل ملف APK الآن' : 'Download APK Now'}
        </a>
        <p className="text-[10px] text-slate-400 mt-2 text-center">
          {lang === 'ar'
            ? 'بعد التحميل: افتح الـ File Manager واضغط على الملف لتثبيته'
            : 'After download: open File Manager and tap the file to install'}
        </p>
      </Card>

      {/* Categories Management */}
      <CategoriesManager />

      {/* Excel Export/Import + Backup */}
      <DataTools />

      {/* Data Management */}

          <h2 className="font-semibold">{t('dataManagement')}</h2>

        <Button variant="outline" onClick={handleReset} className="w-full text-red-600 border-red-200 hover:bg-red-50">

      <Card className="p-4">

          <h2 className="font-semibold">{t('about')}</h2>

          <p>Next.js 16 + PWA + Prisma</p>
