# مراجعة تطبيق محفظتي (MyWallet) - وصف كامل

## نظرة عامة
تطبيق إدارة مالية شخصي (Expense Tracker) مبني بـ Next.js 16 + TypeScript + Prisma + SQLite
يدعم: عربي (RTL) + إنجليزي (LTR) | Dark Mode | PWA (قابل للتثبيت على الموبايل) | APK للأندرويد

## الشاشات الرئيسية (5 تبويبات)

### 1. الشاشة الرئيسية (Home) - مدموجة مع المعاملات
- **بطاقة الرصيد**: إجمالي الأصول بعملة العرض (مع تدرج لوني أزرق)
- **ملخص سريع**: 3 كروت (اليوم / الأسبوع / الشهر) - دخل + مصروف بصيغة مختصرة (2.4K)
- **بحث ذكي**: بالاسم أو المبلغ أو الملاحظة
- **زر ترتيب**: الأحدث فوق / الأقدم فوق
- **فلتر تاريخ**: من - إلى (افتراضي: الشهر الحالي)
- **فلتر نوع**: الكل / مصروف / دخل
- **فلتر فئة**: أي فئة
- **قائمة المعاملات**: مجمعة باليوم - كل يوم يعرض إجمالي دخل/مصروف
- **التحويلات مش بتظهر هنا** (فصلناها عن المصروفات)

### 2. شاشة الفئات (Categories)
- **فلاتر زمنية**: اليوم / الأسبوع / الشهر / السنة
- **بحث بالاسم**
- **ملخص**: إجمالي الدخل + إجمالي المصروف
- **قائمة الفئات**: كل فئة فيها:
  - أيقونة ملوّنة + اسم (عربي/إنجليزي)
  - المبلغ الإجمالي + عدد المعاملات
  - شريط نسبة مئوية
- **اضغط على فئة** → تفتح modal فيها:
  - الإجمالي + عدد المعاملات
  - قائمة كل معاملات هذه الفئة في الفترة المحددة

### 3. شاشة الحسابات (Accounts)
- **ملخص علوي**: الأصول / الخصوم / الصافي (3 كروت ملونة)
- **بحث بالاسم**
- **حسابات مجمعة حسب النوع** (8 أنواع):
  - كاش | بنوك | محافظ إلكترونية | بطاقات ائتمان | حسابات توفير | استثمارات | حسابات خارجية | قروض وسلف
- كل حساب يعرض: الرصيد بعملته الأصلية (مش محوّل)
- **اضغط على حساب** → تفتح صفحة تفاصيل فيها:
  - الرصيد الحالي بعملته
  - ملخص: دخل / مصروف / تحويل (لهذا الحساب)
  - قائمة معاملات هذا الحساب
- زر تعديل + زر حذف لكل حساب

### 4. شاشة التقارير (Reports)
- **تبديل شهري / سنوي**
- **شهري**: اختيار شهر + ملخص (دخل/مصروف/صافي + نسبة ادخار)
- **مقارنة بالشهر الماضي**: زيادة/نقصان بنسبة مئوية (↑↓)
- **رسم بياني**: دخل vs مصروف يومياً (Bar Chart)
- **Donut Chart**: توزيع المصروفات حسب الفئة مع Legend + نسب مئوية
- **Top 10 Categories**: قائمة بأعلى الفئات مع شريط تقدم
- **سنوي**: اختيار سنة + رسم بياني 12 شهر + جدول مقارنة
- **تصدير**: Excel + PDF

### 5. شاشة الإعدادات (Settings) + الميزانية
- **اللغة**: عربي/إنجليزي (تبديل فوري + حفظ)
- **العملة الأساسية**: EGP / SAR / USD / EUR / AED
- **المظهر**: فاتح / داكن / النظام
- **التنبيهات**: toggle
- **تثبيت التطبيق**: (PWA install)
- **إدارة الفئات**: إضافة/تعديل/حذف (تبويبات: مصروف/دخل)
- **Excel**: تصدير/استيراد (متوافق مع Money Manager)
- **Backup**: تحميل/استعادة (JSON)
- **تذكير الفواتير**: (schema + API جاهز)
- **تحديث أسعار الصرف**: (localStorage)
- **حذف كل البيانات**: (زر مسح سريع)
- **تسجيل الخروج**

## ميزات إضافية

### نظام تسجيل الدخول
- إيميل + كلمة سر (مجاني)
- كل إيميل له بياناته لوحده (userId)
- تسجيل دخول/خروج + session cookie
- كلمة السر مشفرة (SHA-256 + salt)

### FAB (زر إضافة عائم)
- 3 خيارات: إضافة مصروف (أحمر) / إضافة دخل (أخضر) / تحويل (رمادي)
- التحويل: من حساب → إلى حساب (مع تحويل عملة تلقائي + زر تبديل)

### العملات المتعددة
- 5 عملات: EGP, SAR, USD, EUR, AED
- كل حساب له عملته الخاصة
- التحويل تلقائي عند الإضافة/التحويل
- عرض الإجماليات بالعملة الأساسية

### نظام التحويلات
- التحويلات مش بتتحسب كمصروف أو دخل
- بتنشأ كنوع TRANSFER (منفصل)
- بتحدّث رصيد الحسابين (المصدر والوجهة)
- لو العملتين مختلفين → تحويل تلقائي

### استيراد/تصدير
- **Excel Import**: متوافق مع ملفات Money Manager (Date/Account/Category/Note/SAR/Income-Expense/Currency)
- ينشئ حسابات وفئات تلقائياً
- يدعم Transfer-Out (تحويل بين حسابات)
- **Excel Export**: 3 صفحات (Transactions + Accounts + Categories)
- **PDF Export**: تقرير شهري بجدول الفئات
- **Backup**: JSON يحتوي كل البيانات

### Dark Mode
- كامل (خلفيات + كروت + ألوان + تباين محسّن)

### PWA
- manifest.json + Service Worker v5
- قابل للتثبيت على المتصفح (Add to Home Screen)
- APK للأندرويد (WebView يحمل الرابط)

## البنية التقنية
- Framework: Next.js 16 (App Router, Turbopack)
- Database: Prisma + SQLite (models: User, Account, Category, Transaction, Budget, RecurringTransaction, SavingsGoal, BillReminder)
- UI: shadcn/ui + Tailwind CSS 4 + Recharts + Lucide Icons
- State: Zustand + persist
- Auth: نظام مخصص (email + password + token)
- Languages: Arabic (RTL) + English (LTR)
